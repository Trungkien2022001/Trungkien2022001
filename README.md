## 🧭 What I do

I build and run the backend of **B2B travel distribution platforms** — the layer that connects travel agencies, airlines and OTAs to dozens of hotel, flight, tour and transfer suppliers through one unified API.

- 🏨 **Hotel gateway (easyGDS / Altovo)** — aggregation service connecting **40+ hotel suppliers** (Juniper, DOTW/WebBeds, Hotelbeds, RateHawk, Rakuten Travel Xchange, Hotelston, Jumeirah, Accomy …) behind one search → prebook → book → cancel API. Koa · MySQL · Redis · AWS SQS workers.
- 🔌 **Supplier integrations end-to-end** — REST / SOAP / XML adapters, offer-matrix pricing, cancellation-policy normalisation, partner certifications, go-lives.
- 🗺️ **Hotel content mapping at scale** — matching supplier catalogues to our inventory with GIATA codes, GPS + name/address scoring (hundreds of thousands of properties per supplier, ~99.8% precision on known mappings).
- 📈 **Performance & reliability** — search pipeline optimisation, caching strategy, Grafana/Loki/Sentry observability, CI/CD on GitLab.
- 🤖 **AI-assisted ops** — internal agents that triage partner chat, investigate bookings and ship fixes.

Previously: product work at **VNTrip** (EMS / approval workflows, flight & insurance services) and side projects in TypeScript / NestJS / Next.js.
